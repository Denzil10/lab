# Lab

Small things I build in public: games, tools and experiments. Live at https://denzil10.github.io/lab/

- [Cart Gate](https://denzil10.github.io/lab/cart-gate/) ([source](https://github.com/Denzil10/cart-gate)): Covers the pay button in shopping and food-delivery apps while the cart holds junk food; remove the item and it lifts. On-device, no internet permission.

## What next? You decide
Each page has a ♥, a feedback box and a subscribe box (one email per new build); [the Lab page](https://denzil10.github.io/lab/#next) takes ideas for new ones. The most-wanted ones get built here.

The ♥, email and text boxes send what you enter, and which page it came from, to a Google Form only I read. Nothing else is collected and nothing is published. An email gets a welcome, then one email per new build; every email has a one-click unsubscribe. MIT licensed.
