# Tools

Free tools I build in public: apps, games and experiments. Live at https://denzil10.github.io/lab/

- [Snack Bouncer](https://denzil10.github.io/lab/snack-bouncer/) ([source](https://github.com/Denzil10/snack-bouncer)): Blocks the pay button in shopping and food-delivery apps while junk food sits in the cart; take it out and you're in. On-device, no internet permission.

## What next? You decide
Each page has a ♥, a feedback box and a subscribe box (one email per new build); [the Tools page](https://denzil10.github.io/lab/#next) takes ideas for new ones. The most-wanted ones get built here.

The ♥, email and text boxes send what you enter, and which page it came from, to a Google Form only I read. Nothing else is collected and nothing is published. An email gets a welcome, then one email per new build; every email has a one-click unsubscribe. MIT licensed.
