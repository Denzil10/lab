# Lab

Small things I build in public: games, tools and experiments. Live at https://denzil10.github.io/lab/

- [Cart Gate](https://denzil10.github.io/lab/cart-gate/) ([source](https://github.com/Denzil10/cart-gate)): Covers the pay button in shopping and food-delivery apps while the cart holds junk food; remove the item and it lifts. On-device, no internet permission.

## What next? You decide
Each page has a ♥, a "tell me when the complete version ships" box and a feedback box; [the Lab page](https://denzil10.github.io/lab/#next) takes ideas for new ones. The most-wanted ones get built here.

The ♥, email and text boxes send what you enter, and which app it is about, to a Google Form only I read. Nothing else is collected and nothing is published. An email is used once, to tell you the complete version is out. MIT licensed.
