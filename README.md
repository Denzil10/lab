# Lab

Small things I build in public: games, tools and experiments. Live at https://denzil10.github.io/lab/

- [Tokendle](https://denzil10.github.io/lab/tokendle/) ([source](tokendle/)): A daily game: five strings, guess how many tokens each costs a language model, then see exactly how the tokenizer cut them.

## What next? You decide
The [wishlist](https://github.com/Denzil10/lab/issues?q=is%3Aissue+is%3Aopen+label%3Awishlist+sort%3Areactions-%2B1-desc) is the issues labelled `wishlist`, ranked by 👍. Vote on the ones you want, or [add a wish](https://github.com/Denzil10/lab/issues/new?template=wish.yml). The most-wanted ones get built here.

Everything is static and runs in your browser; nothing you type is sent anywhere. MIT licensed.
